# Digital Market Intelligence v1.0.0

Initial release of the Similarweb-style digital market intelligence Agent Skill.

### Included
- Website and competitor research workflows
- Acquisition channels, SEO and keyword-gap analysis
- Sampled AI-search visibility analysis
- Mobile app, e-commerce, and prospect research workflows
- Source map and market-intelligence report template
- Evidence labeling, uncertainty handling, citation, and responsible-access principles

### Important limitation
This release provides agent instructions and report scaffolding. It is not a hosted analytics product and does not include licensed traffic, keyword, app, or marketplace datasets. Provider access and API credentials must be configured separately.
