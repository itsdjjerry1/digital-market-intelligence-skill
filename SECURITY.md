# Security and responsible data use

Do not commit API keys, access tokens, private customer data, or other secrets. Use the relevant provider's secure credential-management mechanism.

Use only public information, authorised APIs, licensed datasets, and user-provided data. Do not bypass logins, paywalls, CAPTCHAs, access controls, rate limits, or robots restrictions. If you discover a security issue in this repository, please report it privately to the repository maintainer rather than publishing exploit details in an issue.
